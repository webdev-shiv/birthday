# How to Add Your Own Photos ❤️

To show real photos in the "Our Little Memories" scrapbook:

1. Copy your photos into this folder (`public/memories/`).
2. Name them:
   - `memory-1.jpg` (or `.png`)
   - `memory-2.jpg`
   - `memory-3.jpg`
   - `memory-4.jpg`
   - `memory-5.jpg`
   - `memory-6.jpg`
3. If using different filenames, update the `image` path in `src/config.js`!

*Note: If no custom photo is added yet, the website automatically displays beautiful illustrated romantic gradient frames with stickers and titles so it always looks stunning!*
